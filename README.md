# Machine Learning-Based System for Automated Content Moderation

A university final-year prototype: TF-IDF + Logistic Regression text classifier
that detects toxic content and routes it to a Safe / Flag for Review / Harmful
moderation decision, served through a simple Flask web app.

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Run the app (see "Running the web app" below). **You do not need `train.csv`
   for this** — the trained model and vectorizer are already included in
   `models/`, and the already-cleaned training data is already included in
   `data/processed/clean_comments.csv`.

3. **Only if you want to retrain from the original raw dataset** (e.g. to
   change the sample size, add more data, or reproduce the preprocessing
   step yourself) do you need `train.csv`:
   - Go to Kaggle: "Jigsaw Toxic Comment Classification Challenge"
     (kaggle.com/competitions/jigsaw-toxic-comment-classification-challenge/data)
   - Download `train.csv.zip`, unzip it
   - Place `train.csv` inside `data/raw/` so the path is `data/raw/train.csv`
   - Then run `python run_preprocessing.py` first, before `train.py`

## Running the pipeline (only needed if retraining — see Setup step 3)

```
python run_preprocessing.py   # needs data/raw/train.csv - cleans it, saves to data/processed/
python train.py                # trains and saves the Logistic Regression model
python evaluate.py             # prints accuracy/precision/recall/F1 + confusion matrix
python compare_models.py       # (optional) compares LR vs Naive Bayes vs SVM vs Random Forest
```

## Running the web app

```
python app/app.py
```

Then open http://127.0.0.1:5000 in a browser.

## Project structure

```
content-moderation-project/
├── data/
│   ├── raw/              (place train.csv here — see Setup above)
│   └── processed/        (cleaned data, generated by run_preprocessing.py)
├── src/
│   ├── data_loader.py    (loads + inspects raw data)
│   ├── preprocessing.py  (text cleaning)
│   ├── features.py       (TF-IDF vectorization)
│   ├── predict.py        (runs trained model on new text)
│   └── moderation.py     (converts prediction into a moderation decision)
├── app/
│   ├── app.py             (Flask backend)
│   └── templates/index.html (frontend)
├── models/                (saved trained model, vectorizer, evaluation outputs)
├── config.py               (paths, thresholds, constants)
├── train.py
├── evaluate.py
├── compare_models.py
├── run_preprocessing.py
├── run_features.py
└── requirements.txt
```

## Reported results (Logistic Regression, on held-out 12,000-row test set)

| Metric | Value |
|---|---|
| Accuracy | 0.9324 |
| Precision | 0.6117 |
| Recall | 0.8289 |
| F1-score | 0.7039 |
